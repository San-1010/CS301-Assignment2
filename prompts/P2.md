Use only the allowed libraries (lists, apply, yall, aggregate), without assert, retract, or global variables.

Include a declarative reading comment and provide test queries for single numbers, multiple numbers, exact division, invalid division, and an empty list.

Do not implement any other predicate or the complete P2 solution.


4. Implement only the predicate format_expression(Tree, String) and any strictly necessary formatting helpers for 26_q2.pl in SWI-Prolog 9.x.

Trees are represented as leaf(N) or node(Op, Left, Right), where Op is +, -, *, or /.

Return a Prolog string with no spaces, using these canonical formatting rules:
- Multiplication and division have higher precedence than addition and subtraction.
- All operators are left-associative.
- Parenthesize a left child only when its top operator has lower precedence than its parent.
- Parenthesize a right child when its top operator has equal or lower precedence than its parent.
- Never parenthesize a leaf.

Ensure that structurally different expression trees produce different strings.

Include declarative reading comments and test queries covering (4+2)*3, 4+2*3, 8/4*2, 8/(4*2), 1-2-3, 1-(2-3), 1+(2+3), and 1+2+3.

Use only the permitted libraries and do not implement generate_equation/2, all_equations/2, or count_equations/2.

The predicate should generate equations through backtracking and fail when no valid equation exists. Do not reorder numbers, introduce unary minus, or use floating-point division.

Include a declarative reading comment and test queries for [4,2,5,3], [2,3,4], [2,4,8], and an empty list.

Use only the permitted libraries. Do not implement all_equations/2 or count_equations/2.
